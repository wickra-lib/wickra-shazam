**[shazam.wickra.org](https://shazam.wickra.org)** — quickstarts, the API
surface for every binding, and the guides.

the implementation and has to change in the same commit as it:

- [`ARCHITECTURE.md`](ARCHITECTURE.md)

page shows it.
